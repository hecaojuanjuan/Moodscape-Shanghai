# Moodscape-Shanghai

Moodscape Shanghai 是一个基于情绪标签的个性化上海城市旅游推荐项目。项目希望不再只按照“景点类型”推荐路线，而是根据用户当下的情绪状态和体验需求，例如独处、浪漫、探索、治愈、社交、文化沉浸等，生成更符合个人感受的城市路线。

本项目目前以上海为初始城市，整理了真实点位、路线、情绪标签、开放时间、预约信息、游客反馈关键词和经纬度数据。用户可以选择情绪标签，或在输入框中描述自己的心情和需求，系统会根据本地数据匹配合适的路线，并接入大语言模型生成对应的城市旅游剧本，同时在地图上展示推荐路线。

项目目标是构建一个“数据真实 + 情绪体验 + AI 生成”的城市旅行网站原型，为用户提供更个性化、更有故事感的城市探索方式。
