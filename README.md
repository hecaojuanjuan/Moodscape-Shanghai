# Moodscape Shanghai

Moodscape Shanghai 是一个基于情绪标签的个性化上海城市旅游路线推荐网站。项目希望不再只按照传统的“景点类型”或“热门程度”推荐路线，而是根据用户当下的情绪状态和体验需求，例如独处、治愈、浪漫、探索、社交、文化沉浸、城市烟火气等，为用户生成更有情绪感和故事感的城市旅行路线。

本项目以上海为初始城市，基于真实点位、路线、情绪标签、开放时间、游客反馈关键词和经纬度数据，构建一个“情绪体验驱动”的城市旅游推荐原型。用户可以选择已有情绪标签，也可以在输入框中输入自己的心情描述，系统会先通过本地推荐模型匹配合适路线，再调用国内大语言模型生成个性化城市旅游剧本，并在地图上展示对应路线。

---

## 项目目标

本项目的核心目标是构建一个：

> 真实城市数据 + 情绪标签推荐 + AI 旅游剧本生成 + 地图路线展示

结合的个性化城市体验网站。

与传统旅游推荐网站不同，本项目更关注用户的心理状态和体验感受。例如：

* 今天想一个人安静地走走
* 想找一条治愈、不赶路的路线
* 想和朋友去有烟火气的地方
* 想体验上海的文化空间
* 想找适合拍照和浪漫氛围的路线

系统会根据这些情绪需求，从本地真实路线数据中匹配合适路线，并生成一段具有画面感和故事感的城市旅游剧本。

## 核心功能

### 1. 情绪标签选择

用户可以从预设的情绪标签中选择自己的当前状态，例如：

* 独处
* 治愈
* 浪漫
* 探索
* 社交
* 文化沉浸
* 城市烟火气
* 慢节奏
* 拍照打卡
* 自然放松

系统会根据用户选择的标签匹配最合适的上海城市路线。

---

### 2. 自然语言输入

如果已有标签不能准确表达用户的心理状态，用户可以在输入框中输入一段自然语言，例如：

```text
我今天有点累，想找一条安静、不赶路、适合一个人慢慢走的路线。
```

系统会对用户输入进行关键词识别，并映射到对应的情绪标签或路线特征。

---

### 3. 本地情绪路线推荐模型

项目会先构建一个轻量级本地推荐模型，而不是直接让大模型生成路线。

推荐模型主要负责：

1. 读取本地路线和点位数据。
2. 分析用户选择的情绪标签。
3. 识别用户输入文本中的关键词。
4. 根据标签匹配度、路线特征和点位属性计算推荐分数。
5. 返回最适合用户当前状态的路线。

这样可以保证推荐结果来自真实数据，而不是由大模型随意编造。

---

### 4. 接入真实国内大模型

在本地推荐模型选出路线后，系统会调用真实国内大语言模型 API，用于生成个性化城市旅游剧本。

大模型主要负责：

* 根据推荐路线生成具有故事感的旅行文案。
* 为每个点位生成符合情绪氛围的体验描述。
* 根据用户当前心情生成开场旁白和结尾文案。
* 提升网站的互动感和内容表现力。

重要原则：

> 大模型只负责“写得更有氛围”，不负责自由编造地点和路线。

所有路线、点位和经纬度都必须来自本地数据集。

---

### 5. 地图路线展示

项目会基于点位经纬度，在地图上展示推荐路线。

初版地图功能可以先实现：

* 展示路线中的所有点位
* 根据点位顺序连线
* 显示点位名称和简介
* 展示推荐路线的整体空间分布

后续可进一步接入高德地图、Leaflet 或其他地图服务，实现更完整的路线可视化。

## 本地运行方法

### 1. 克隆项目

```bash
git clone 仓库地址
cd Moodscape-Shanghai
```

### 2. 创建虚拟环境

Windows：

```bash
python -m venv venv
venv\Scripts\activate
```

macOS / Linux：

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 配置环境变量

复制 `.env.example` 文件，并创建 `.env` 文件：

```bash
cp .env.example .env
```

在 `.env` 中填写真实大模型 API Key：

```env
DASHSCOPE_API_KEY=your_api_key_here
LLM_MODEL=qwen-plus
```

注意：
`.env` 文件中包含 API Key，不应该上传到 GitHub。

---

### 5. 启动项目

```bash
python app.py
```

然后在浏览器中打开：

```text
http://127.0.0.1:5000
```

## 大模型使用原则

为了保证推荐结果真实可靠，本项目对大模型使用设置了明确限制：

1. 大模型不能自由编造景点。
2. 大模型不能修改本地推荐模型给出的路线顺序。
3. 大模型不能编造开放时间、门票价格或预约信息。
4. 大模型只能基于系统提供的路线和点位信息生成文案。
5. 大模型主要负责生成具有情绪氛围和故事感的旅游剧本。

## 项目特色

本项目的特色在于：

1. 不是普通景点推荐，而是基于用户情绪状态进行路线推荐。
2. 不是让 AI 随机生成旅游攻略，而是基于真实上海数据生成内容。
3. 将本地推荐模型与大语言模型结合，提高推荐结果的可信度和表现力。
4. 通过地图展示路线，使用户可以直观看到城市体验路径。
5. 适合作为 AI + 城市体验 + 个性化推荐方向的网站原型。

---

## 项目定位

Moodscape Shanghai 试图探索一种新的城市旅游推荐方式：

> 从“我想去哪”转向“我现在想获得什么样的城市体验”。

通过情绪标签、本地真实数据和 AI 生成能力，项目希望为用户提供更个性化、更有故事感的上海城市探索方式。
